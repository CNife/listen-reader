# ADR-0002: 采用 Notion 设计语言，蓝色行动与唯一夜色岛

- 状态：已接受
- 日期：2026-11-27

## 背景

旧的界面以赭红作强调色、纯白作页底，大量分组靠分隔线，浅色与暗色骨架也不一致。用户在资料库、采集、预览、朗读、设置之间移动时看到的是功能清单，而不是一张适合长时间阅读的纸。评审稿把 Notion 的暖纸底、白面卡片、发丝线、单一蓝色行动和一块深色 hero 区作为方向，并已确认全量重塑、系统 sans、继续收听卡用深蓝夜色。

## 决策

1. **蓝色取代赭红，成为唯一的结构性强调色。** `#0075DE` 只用于主操作、选中态和进度填充；链接用更深的 `#005BAB`，暗色提亮到 `#62AEF0`。不再保留第二个强调色，状态、错误与破坏性动作都不用语义红/绿按钮，避免与品牌蓝争夺「这里可以点」的信号。
2. **不打包 Inter，中文不收紧字距。** 使用系统 sans；负字距只用在 22sp 及以上的标题（资料库 32/−0.6、播放与预览 24–26/−0.3），正文与按钮的字距为 0。中文字形本身已经紧密，继续压字距会牺牲可读性；只有在字号足够大时才用负字距制造标题的整块感。
3. **整页只有一个深色岛。** 「继续收听」Resource 卡是唯一的深色块（浅色 `#213183`、暗色 `#2A3166`），其余分组全部回到白面、发丝线和留白。天空、紫、青、绿、橙、粉只作为 Source 类型瓦片、流程点与状态点的装饰，永不填充按钮或整块结构。

## 补充决策

- 卡片 12px、夜色岛与对话框 16px、输入 4px、CTA 全圆药丸；默认层级靠 1px 发丝线，只有弹层与对话框允许轻微抬升。对话双方的操作仍以文字链接 + 唯一蓝色药丸呈现。
- 浅色纸底元信息用 `#716C65`、白面元信息用 `#78736C`，暗色统一 `#9A958E`。输入边线的 `#DDD`（暗色 `#3A3A37`）低于 WCAG 1.4.11 的 3:1 要求，是有意保留的评审稿例外：字段同时有标签与占位符，不只靠边线识别，聚焦时边线换成蓝色。
- 暗色与浅色同构，只换 token；布局、间距、字号、语义角色、testTag 与交互全部复用。视觉正确性由 `UiSnapshotTest` 的真实渲染快照逐张人工复核，不在断言里锁颜色值。

## 后果

- `ui/theme/` 的 `LrColors` 成为唯一的 token 出口；新增界面只允许从这里取色，贴纸色仅用于装饰场景。
- 后续若增加结构性强调色或第二个深色岛，需要新的 ADR，而不是在界面里局部加色。
- 删除或改动按钮、状态卡的形态时，先确认主操作仍然唯一、深色岛仍然唯一。
